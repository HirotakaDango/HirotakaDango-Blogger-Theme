# HirotakaDango Blogger Theme

A minimalist, borderless template for Google Blogger built around the Material Design 3 design system. It focuses on clean typography, smooth elevations, mobile responsiveness, and zero-line visual architecture with native light and dark modes.

KEY FEATURES
1. Material Design 3 Palette: Uses custom CSS design tokens for primary, container, surface, and elevation layers, alongside a uniform 10px corner radius across all cards, buttons, and modals.
2. Instant Theme Switching: Detects system color preference on initial page load and allows visitors to switch between light and dark modes with states preserved in localStorage.
3. Interactive Live Search: YouTube-style search modal that queries Blogger JSON feeds in real time and shows post titles, thumbnails, and dates before submitting.
4. Minimalist Share Modal: Borderless modal with direct icons for WhatsApp, X (Twitter), Facebook, Telegram, Email, copy-to-clipboard, and native device Web Share API support.
5. Infinite Load More: Feed loader that loads 15 articles per batch on demand or via scroll detection without reloading the entire webpage.
6. Instant Feed Sorting: Reorder active posts directly on the client side by Newest, Oldest, or Alphabetical (A to Z) order.
7. Clean Single Post View: Distraction-free reading environment with clean typography, styled blockquotes, mobile-friendly tables, collapsible comment drawer, and an author profile card.

HOW TO INSTALL
1. Log in to your Google Blogger dashboard.
2. Go to the Theme menu from the left navigation.
3. Click the downward arrow next to the Customize button and choose Restore.
4. Select the HirotakaDango_Blogger_Theme.xml file from your computer. Alternatively, choose Edit HTML, delete all existing code, paste the entire XML contents, and save.
